RESQ-AI - GEMINI SETUP

1. Open backend/.env.example.
2. Save a copy as backend/.env.
3. Put your Gemini API key after GEMINI_API_KEY=.
4. Leave GEMINI_MODEL=gemini-2.5-flash-lite.
5. Open a terminal in backend and run:

   python -m pip install -r requirements.txt
   python -m uvicorn main:app --reload --port 8000

6. In a second terminal:

   cd frontend
   npm install
   npm run dev

7. Open http://localhost:5173
8. Check http://localhost:8000/api/health. It should show llm_mode as live.

IMPORTANT:
Do not commit backend/.env to Git. It is already ignored by .gitignore.
If an API key has been posted publicly or shared in chat, revoke it and create a new one before using it.
